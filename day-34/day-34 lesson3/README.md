# Breast Cancer Classification Project

A python project that trains a classifier 
on the load_breast_cancer dataset from scikit-learn.



## Installation

python -m pip install -r requirements.txt

## Training

python train_model.py

## Prediction

python predict.py

## Outputs

- models/breast_cancer_pipeline.joblib
- models/metadata.json

THIS PROJECT IS FOR EDUCTAIONAL PURPOSES AND MUST NOT 
BE USED FOR CLINICAL DIAGNOSIS OR TREATMENT DECISIONS.
